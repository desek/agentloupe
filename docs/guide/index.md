# User guides

The README and the guides under `docs/guide/` are the authority for the user.

- [Quickstart](quickstart.md): Full quickstart: configure, start the container, make a token, connect the agents, and open the dashboard.
- [Overview](overview.md): Status of loupe, its scope, how it works, and the open work.
- [The loupe binary](loupe-binary.md): The subcommands of the loupe binary and what each one does.
- [Dashboard and private page](dashboard.md): The public dashboard, its live section, and the private page on localhost.
- [Proxy tokens](proxy-tokens.md): How to make, list, and revoke the proxy tokens that the agents use.
- [Install](install.md): Install loupe from a release asset, the registry image, or the source, and check a release.
- [Connect the agents](connect-agents.md): Connect Claude Code and Pi to the loupe proxy.
- [Accounts and cost](accounts-and-cost.md): How loupe finds the accounts and calculates the cost of the calls.
- [GitHub](github.md): How loupe reads the pull request counts from GitHub, and the token permissions.
- [Privacy model](privacy.md): What leaves the machine, what stays, and the start request of the release builds.
- [Public hosting](public-hosting.md): Run the public instance that serves only the public page and the public API.
